# Real-Time Face Mask Detection System

## Project Overview
This project aims to develop a **real-time face mask detection system** that can automatically detect whether a person is wearing a mask or not using live video or camera input. The system is designed to help improve public safety and health monitoring by automating mask detection in public spaces such as offices, schools, or transport stations.

## Objective
The main goal is to create a simple yet effective solution using Python that can:
- Detect human faces in real-time video streams.
- Classify whether the detected face is wearing a mask or not.
- Operate efficiently with minimal delay.

## Technologies Planned
- **Programming Language:** Python  
- **Libraries/Frameworks:**  
  - OpenCV – for face detection and video processing  
  - TensorFlow / Keras – for building and training a Convolutional Neural Network (CNN)  
  - NumPy and Pandas – for data handling  
  - Matplotlib – for visualization  

## Planned Methodology
1. **Data Collection:** Use publicly available face mask datasets.  
2. **Preprocessing:** Resize, normalize, and augment image data for better training.  
3. **Model Development:** Train a CNN model to classify masked and unmasked faces.  
4. **Testing:** Evaluate the model on unseen data for accuracy and speed.  
5. **Deployment:** Integrate the trained model with a real-time video stream using OpenCV.  

## Expected Outcome
By the end of this project, I aim to deliver a **working prototype** capable of detecting faces and determining if masks are worn correctly in real-time. The system will be lightweight, accurate, and suitable for demonstrations or further development.
