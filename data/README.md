# Dataset Usage

The dataset used for training this model is **not included in this repository**  
due to size and licensing restrictions.

You can download the dataset from Kaggle here:

<LINK [TO THE KAGGLE DATASET](https://www.kaggle.com/datasets/andrewmvd/face-mask-detection)>

After downloading, place the folders as follows:

Mask-Detection-System/
    data/
        train/mask
        train/no_mask
        val/mask
        val/no_mask
        test/mask
        test/no_mask
